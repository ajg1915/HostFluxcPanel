cPanel self-hosting setup

A checklist for installing cPanel on a server you control. Tick each step as you go. Your progress is saved in this browser.

Use a fresh server. cPanel needs a clean Linux install. Installing it on a server that already runs websites or mail can break them. Back up first.

1. Check the server requirements

  • Linux: AlmaLinux, Rocky Linux or CloudLinux, with a version cPanel currently supports.
  • Memory: cPanel's documented minimum is 1 GB RAM. For real sites, plan for more.
  • A static public IP address and root SSH access.
  • A domain name you can point at the server, for example server.yourdomain.com.
  • A cPanel license. cPanel offers a trial, but a paid license is needed after that. Check current terms at cpanel.net.

3. Install cPanel

Log in as root over SSH, then run the official installer. The install takes a while, often 30 to 90 minutes.

cd /home && curl -o latest -L https://securedownloads.cpanel.net/latest && sh latest

Watch the progress in another SSH window:

tail -f /var/log/cpanel-install.log
